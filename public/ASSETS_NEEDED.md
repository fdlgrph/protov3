Add these files here before deploying for best results:

- resume.pdf     -> used by the "Download CV" button
- og-image.jpg   -> 1200x630px, used for social share previews (Open Graph / Twitter Card)
- favicon.ico    -> browser tab icon
- mascot.png     -> optional: self-hosted copy of your mascot; then set
                    MASCOT_SRC = "/mascot.png" in lib/site-config.ts instead
                    of the external hotlink URL.
